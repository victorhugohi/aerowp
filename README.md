# Pagina Web de Introducción a la Aeronáutica

## Descripción
Este proyecto es una página web educativa diseñada para introducir a los estudiantes en los conceptos básicos de la aeronáutica.

## Equipo
- **Estudiantes:** Creadores de Contenido y Testeadores.
- **Docente:** Desarrollador Principal.

## Estructura del Proyecto
- `src/`: Código fuente (CSS, JS, Assets).
- `docs/`: Documentación y PRD.
- `en/`: Versión en inglés del sitio.
- `*.html`: Archivos HTML principales (Español).
